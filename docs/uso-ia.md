# Autoría y uso de IA

## Uso de IA

Herramienta: Claude Code (Anthropic), modelo Claude Opus 5.5.

Uso:

- **Guía paso a paso**: explicación de cada paso del enunciado y de los
  conceptos (PID, PPID, hilos, `ProcessBuilder`, pipes…). El alumno escribe y
  ejecuta el código.
- **Fragmentos de código de ejemplo**: cada fragmento propuesto lleva un
  comentario que explica para qué sirve. El alumno lo revisa, lo integra y
  comprueba que funciona.
- **Resolución de errores**: diagnóstico de incidencias (ver
  [Incidencias.md](Incidencias.md)).
- **Redacción de la documentación** (`README.md` y `docs/`), a partir de las
  pruebas y los resultados obtenidos por el alumno.

## Verificación

Todas las propuestas se han verificado compilando y ejecutando el programa en
el entorno del laboratorio antes de integrarlas.
